# algo_practice

I used to do algo practice. I still do, but I used to, too.

This is a few hundred algorithm and data structure problems I worked through in JavaScript and Ruby. Most of them come in two versions. One is the solution. The other is the same solution with a comment on every line explaining what it does and why. Writing the explained version is how I made sure I actually understood it.

## What's in here

| Folder | What it is |
| --- | --- |
| `javascript/algoLadder` and `ruby/algo_ladder` | The [algorithm ladder](https://trello.com/b/smxNsfu6/algorithm-ladder), starting easy and working up |
| `javascript/leetcode` | LeetCode problems, split into easy, medium and hard |
| `javascript/interviewing.io` | Problems from sessions on interviewing.io |
| `javascript/interviewCake` and `javascript/algoexpert` | Interview Cake and AlgoExpert problems |
| `javascript/udemyDataAndAlgos` and `ruby/data_stuctures` | Linked lists, stacks, queues, trees and sorting from scratch |
| `javascript/repeat` | Problems I came back to and solved again later |
| `javascript/random` and `ruby/random` | Whatever else I ran into |

## Running one

Most files run by themselves and print their answers.

```sh
node javascript/algoLadder/3and5/3and5.js
ruby ruby/algo_ladder/100_coolio_array/100_coolio_array_explained.rb
```

## Where the problems come from

* [Algorithm ladder](https://trello.com/b/smxNsfu6/algorithm-ladder) for the basics
* LeetCode's top interview questions, [easy](https://leetcode.com/explore/interview/card/top-interview-questions-easy/), [medium](https://leetcode.com/explore/interview/card/top-interview-questions-medium/) and [hard](https://leetcode.com/explore/interview/card/top-interview-questions-hard/)
* [LeetCode patterns](https://seanprashad.com/leetcode-patterns/), which sorts problems by the trick that solves them

I also work through interview questions on [YouTube](https://www.youtube.com/c/taylordorsett).
